# FRONTEND DEVELOPMENT RULES & RESPONSIVE DESIGN STANDARDS

## CORE PRINCIPLES

1. Always use Mobile-First Development.
2. Every component must be responsive.
3. Parent container controls child behavior.
4. Never use fixed widths unless absolutely necessary.
5. Prefer:

   * Flexbox
   * CSS Grid
   * Relative units (%, rem, em, vw, vh)
   * max-width over fixed width
6. Prevent horizontal scrolling on all devices.
7. Design for real devices, not only breakpoints.
8. Maintain consistent spacing throughout the application.
9. Ensure accessibility on all screen sizes.
10. Optimize for performance and readability.

## PARENT-FIRST RESPONSIVENESS RULE

Every component must adapt according to the parent container.

Hierarchy:

Parent Container
↓
Grid/Layout
↓
Card Width
↓
Image Width
↓
Content Width
↓
Typography
↓
Icons

Never resize child components before evaluating the parent container.

When screen size decreases:

1. Reduce container width
2. Reduce padding
3. Reduce margins
4. Reduce gaps
5. Reorganize layout
6. Reduce image size
7. Reduce icon size
8. Reduce text size

Never reduce typography first.

* Product Cards
* Service Cards
* Team Members
* Blogs
* Testimonials
* Categories
* Projects
* Portfolios

Rules:

Show View More button.

9-20 Items:
Display first 6.
Expand on demand.

20+ Items:
Use Pagination,
Lazy Loading,
Infinite Scroll,
or Virtualization.

Never render large lists unnecessarily.

2. Optimize assets.
3. Avoid excessive DOM nesting.
